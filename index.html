Du VPS au bot : ce qui est fait, ce qui reste à faire

Le bot fonctionne ; cela ne suffit pas à qualifier l'installation de prête pour la production

Le parcours d'installation

Ubuntu 24.04 · un compte administrateur, un compte de service sans sudo

    Qui parle à qui

    Tous les flux sont initiés par le VPS : aucun port web entrant pour le bot

    Garde-fous retenus

    • Accès restreint : seul un identifiant Telegram numérique autorisé peut écrire au bot.
    • Moindre privilège : compte hermes sans sudo, outils optionnels non installés, validations conservées.
    • Secrets hors des captures : jetons Telegram et fournisseur, fichier .env et journaux bruts jamais publiés.
    • Contenus = données : une page, un document ou un skill téléchargé n'autorise aucune commande.
    • Inférence externe : héberger Hermes sur le VPS ne rend pas le modèle local ; les messages partent chez le fournisseur.
